Overview

In this project I implement spatial filtering from scratch and explore frequency-based effects. Part 1 covers discrete 2D convolutions, finite differences, Gaussian/DoG; Part 2 covers unsharp masking, hybrid images, Gaussian/Laplacian stacks, and multi-resolution blending.

Part 1.1 — Convolutions from Scratch

I implement convolution with four loops (naive) and with two loops (vectorized inner product), and compare against scipy.signal.convolve2d using the same padding/boundary. We evaluate three kernels: 9×9 box (smoothing), $D_x=[1,0,-1]$ (horizontal diff), $D_y=[1,0,-1]^T$ (vertical diff).

Part 1.1 — Key Code Snippets

setup(): grayscale, zero padding, kernel flip 
def setup(image, kernel):
    if image.ndim == 3:
        image = np.mean(image, axis=2).astype(np.float32)
    else:
        image = image.astype(np.float32)
    ph, pw = kernel.shape[0]//2, kernel.shape[1]//2
    padded = np.pad(image, ((ph,ph),(pw,pw)), mode='constant', constant_values=0)
    flipped = np.flipud(np.fliplr(kernel))
    return padded, flipped
convolve_4(): four nested loops 
def convolve_4(image, kernel):
    if image.ndim == 3: image = np.mean(image, axis=2).astype(np.float32)
    else:               image = image.astype(np.float32)
    padded, flipped = setup(image, kernel)
    H, W = image.shape; kH, kW = flipped.shape
    out = np.zeros((H, W), dtype=np.float32)
    for i in range(H):
      for j in range(W):
        acc = 0.0
        for m in range(kH):
          for n in range(kW):
            acc += padded[i+m, j+n] * flipped[m, n]
        out[i, j] = acc
    return out
convolve_2(): two loops + vectorized inner product 
def convolve_2(image, kernel):
    if image.ndim == 3: image = np.mean(image, axis=2).astype(np.float32)
    else:               image = image.astype(np.float32)
    padded, flipped = setup(image, kernel)
    H, W = image.shape; kH, kW = flipped.shape
    out = np.zeros((H, W), dtype=np.float32)
    for i in range(H):
      for j in range(W):
        region = padded[i:i+kH, j:j+kW]
        out[i, j] = np.sum(region * flipped)
    return out
convolve_scipy(): reference 
def convolve_scipy(image, kernel):
    if image.ndim == 3: image = np.mean(image, axis=2).astype(np.float32)
    else:               image = image.astype(np.float32)
    return convolve2d(image, kernel.astype(np.float32),
                      mode='same', boundary='fill', fillvalue=0.0).astype(np.float32)

Part 1.1 — Runtime & Boundary Handling

Boundary handling. I use zero padding and return an output of the same size as the input (“same” convolution). This lets the kernel touch the borders; a slight intensity change near the frame is expected. SciPy is configured with boundary='fill', fillvalue=0 to match my implementation.

Runtime. Four loops iterate pixels and kernel: $\mathcal{O}(H\,W\,k_h\,k_w)$. Two loops keep the same order but rely on NumPy’s vectorized inner product, which is much faster. SciPy is C/Fortran & SIMD optimized; for huge kernels FFT-based convolution also helps.

Part 1.3 — Derivative of Gaussian (DoG)

The plain difference operator is noisy. To reduce noise we first blur with a Gaussian $G$ and then take finite differences (two-step). We can get the same result in one step by pre-combining the filters: build derivative-of-Gaussian kernels DoG$_x = G * D_x$ and DoG$_y = G * D_y$, then convolve them with the image. Both pipelines should match except near borders (different padding extents).

For fair display, I normalize each pair (two-step vs. DoG) to the same intensity range. I also show the absolute-difference maps and a small table with global and inner-region errors.

Part 2.1 — Image “Sharpening” (Unsharp Mask)

Idea. A Gaussian blur keeps only low frequencies. If we subtract that blurred image from the original, we get the high frequencies (fine details & edges). To make the image look sharper, we add a scaled version of those high frequencies back:

sharp = I + α · (I − blurσ)    (aka high-boost)

Here I show, for each image, the blurred, high-frequency, and sharpened results, and how the outcome changes as I vary the sharpening amount α. I keep a moderate Gaussian (σ chosen once per image); higher α strengthens edges but can cause halos and amplify noise.
